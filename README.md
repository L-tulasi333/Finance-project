# Finance-project
Financial Statement Analysis using Excel &amp; Python (EDA) – analyzing 100 companies over 10 years to evaluate revenue trends, profitability, and financial performance.

A comprehensive financial analysis project involving 100 companies over a 10-year period. The project applies data cleaning, trend analysis, and financial ratio evaluation to assess company performance, identify risks, and generate actionable business insights using Excel and Python.

performed exploratory data analysis (EDA) on multi-company financial data using Python (Pandas, Matplotlib). Implemented ratio analysis, trend visualization, and data validation to evaluate revenue growth, profitability, and financial stability.
